Descargar Nova Client

Para Windows. Se instala y se actualiza solo cuando sale una versión nueva.

⬇ Descargar NovaClient-Setup.exe
1Descarga e instala el .exe
2Inicia sesión con Microsoft (o juega sin premium)
3Elige versión y dale a Jugar

Si Windows muestra "Windows protegió su PC", toca Más información → Ejecutar de todas formas. Es porque el instalador no tiene firma de pago.

Nova Client no está afiliado a Mojang ni a Microsoft. Minecraft es una marca de Mojang AB.
